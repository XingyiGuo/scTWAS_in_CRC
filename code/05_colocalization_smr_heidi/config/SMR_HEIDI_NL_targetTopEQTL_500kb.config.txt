# ==============================================================================
# SMR + HEIDI configuration: NL peakSNP-TWAS significant genes
#
# Design:
#   * build SMR/HEIDI tasks directly from the NL 7-cell-type TWAS-significant table
#   * gene cis region = TSS +/- 500 kb
#   * use the same GWAS cohort and source-matched eQTL as coloc
#   * target SNP = SNP with the smallest eQTL p-value among harmonized
#                  GWAS x eQTL overlapping SNPs in the +/-500-kb region
#   * SMR is run with --target-snp so the selected target is forced
#
# Prepare:
#   Rscript prepare_SMR_HEIDI_inputs_targetTopEQTL_500kb.R all \
#     SMR_HEIDI_NL_targetTopEQTL_500kb.config.R
#
# Run:
#   bash run_SMR_HEIDI_targetTopEQTL_500kb.sh \
#     <output_dir>/SMR_HEIDI.NL.all_requested_tasks.manifest.tsv
# ==============================================================================
